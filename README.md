# tailamphat/tap

Homebrew casks by tailamphat.

```sh
brew install --cask tailamphat/tap/treatly
brew install --cask tailamphat/tap/visor
```

| Cask | What it is |
|---|---|
| [treatly](https://github.com/tailamphat/treatly) | A desktop pet that turns your Apple Reminders into treats and nags you to finish them |
| [visor](https://github.com/tailamphat/visor) | A notch app for AI agent usage, approvals, clipboard and music |
